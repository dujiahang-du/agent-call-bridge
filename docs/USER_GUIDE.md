# 使用与补齐清单

## 启动
Windows 10/11 x64：解压发行 ZIP 到本人可写的文件夹，双击 `Start.cmd`。发行包带 Node 运行时与生产依赖，无需 npm、编译器或管理员权限。浏览器入口默认 `http://127.0.0.1:17860`，必须从启动器打开才能取得本机会话。

源码开发：Node 22.18+ 或受支持的 Node24；运行 `npm ci`、`npm run build`，再运行 `Start.cmd`。停止后台服务用 `powershell -NoProfile -File scripts/stop.ps1`；界面的紧急停止只暂停通知，不退出软件。

首次进入向导选择 Mock → 接听设置可留空 → 中文试听 → 保存。运行模拟通话，再打开 Agent 接入并点击接入当前项目。它合并可撤销的 AGENTS 管理块，保留原文；不会修改全局 Codex 配置或其他项目。

## 现有 Codex 桌面任务
Agent 用已存在的终端工具调用 `Bridge.cmd ping`、`report` 或 `report-and-wait`。当前活动任务可立即调用，后续任务读取安装的项目约定。安装文件不等于接入成功：必须收到实际 Agent 联系及上报。

CLI 从当前环境读取真实任务标识，连接凭据不放进命令参数。`report-and-wait` 只允许当前问题选项，并把回复返回仍在等待的同一任务。已结束、退出或超时的任务不能自动唤醒；请回到原任务继续。不能保证模型一定遵从项目约定调用 Bridge，未注册/未上报的崩溃也无法自动获知。

显式 heartbeat 仅用于主动登记的活动任务。长期无信号称“疑似无进展”，不认定任务失败。普通回复轮次结束不等于任务验收通过。

可选 MCP 使用 `dist/bridge/mcp.js`，产品附带实际 stdio server；项目配置须受信任，运行中的 Codex 可能需重新打开任务后才加载。以真实 ping/report 验证为准，不绕过 Hook/MCP 信任。托管 Codex 使用独立 home，不接管桌面任务；模型执行与实际问答回传的验证等级见验收报告。

## 真实电话：集中补齐
请在界面填写，不要把完整 Key、验证码或号码发送到聊天、Issue 或 GitHub。

| 路线 | 必须自行取得的条件 | 费用/限制 |
| --- | --- | --- |
| Twilio | 支持地区的目标号码、账户、Auth Token、可用主叫和地区权限；双向需只转发回调端口的 HTTPS 地址 | 不支持 +86；号码、通话与语音能力可能收费，按目标地区报价 |
| 阿里云 VMS | 符合要求的企业主体、独立语音资质与场景审核、公共模板、最小权限 AccessKey | 不接受个人直接开通；当前公共模式 ¥0.11/分钟，模板内容受审核限制 |
| SIP | 真实服务器、账号、密码、分机和网络条件 | 服务商可能收费；实验性 UDP/TCP，无 TLS/SRTP，不保证公网 NAT 或运营商兼容 |
| ATA | 合适的 SIP/FXS 设备、模拟话机及供电/网络 | 硬件另购；FXS 不会自行提供市话外线，接模拟外线需 FXO 或其他线路 |

**个人 +86 手机外呼线路尚未落实。填 Key、手机号或成功注册平台不保证可拨通。** 本地语音、Mock 和 SIP 软件测试均不能替代手机外呼验收。

第一次真实通话须单独明确授权。先保存配置、检查资质/线路/回调、设置控制 PIN，再在真实电话授权区核对目标与费用。保存设置本身从不触发电话。受限自动授权只在本次运行有效，暂停、改配置或重启后失效。

Twilio回调入口与管理界面分离，具体端口及转发规则见 providers.md。不要公开管理端口。电话按键先验证 PIN，只能答当前任务允许的低风险选项，不能批准命令、权限或任意系统操作。阿里云 SingleCallByTts 已受理后可能无法中途挂断。

## 换电脑与隐私
发行包不含任何人的 `.local`。Windows 凭据由 DPAPI 绑定当前用户/机器，不能把加密文件当成跨电脑可用凭据。换电脑重新解压、重新填电话服务参数和凭据、重新登录独立 Codex 环境、重新授权；不要复制 `.local`、认证、数据库、原始记录或录音到 GitHub。

中文音色取决于新电脑已安装的系统声音。先运行 `runtime/node.exe scripts/doctor.mjs`，再试听并做 Mock 测试。缺少中文声音时使用系统设置安装中文语音需要本人处理；配置和文本 Mock 仍可用。

## 故障排查
- 页面未认证：使用 Start.cmd 重新打开，不复制本机访问 token 给别人。
- 端口占用：停止本项目已记录的服务；不要随意结束其他进程。可通过进程级 `ACB_PORT` 换端口。
- 保存后真实授权消失：正常保护行为，核对目标后重新显式授权。
- 通知显示 unknown：是否受理未知，不会自动重拨；先到服务商查 Call ID。
- SIP 找不到程序：便携包应有 `native/sip/baresip.exe` 和校验清单；只使用本项目验证过的固定构建。
- 语音生成失败：检查系统中文语音；界面仍可配置其他部分。
- 查看 `.local/server.stderr.log` 前注意隐私，不直接上传原始运行目录。报告问题只提供脱敏摘要。

项目采用检查点自动安全同步；不安装持续后台备份任务，不承诺会话结束后自动继续开发。
