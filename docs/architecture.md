# Implementation contract

Single package, TypeScript ESM. Imports use .js for server modules. Fastify API under /api, web dist at dist/web. Node22 SQLite persistence. All runtime files below .local (ACB_DATA_DIR can override only explicitly in tests). No real network calls from tests except local stubs.

Ownership: core agent owns src/core, src/server, src/bridge, tests/core*. Provider agent owns src/providers and tests/providers*. SIP agent owns src/sip, scripts/build-sip*, tests/sip* and docs/sip.md. Root owns src/web, shared contracts, package/build configs, docs, release/security scripts, UI tests. Agents must not edit other areas or commit.

## Server/desktop contracts
- createApp({dataDir?,providers?,testMode?}) returns FastifyInstance; expose app.acb or named exported context if needed. main.ts starts 127.0.0.1:17860, environment ACB_PORT override. app UI and Bearer API use local token file. Launcher obtains auth via fragment, never prints token in logs; web reads token from fragment/sessionStorage. No permissive CORS. Health /health contains no private data. Tests use isolated temp dirs.
- GET /api/status => {mode,paused,realCallsEnabled,connectedAgents,lastEventAt,capabilities}; GET /api/config => masked settings with secret fields blank; PUT /api/config merges blank secrets preserving old, explicit null clears. GET /api/events, /api/notifications, /api/decisions => arrays. POST /api/events => {event,notification?,duplicate}; POST /api/decisions/:id/respond body {optionId,pin?}; GET /api/decisions/:id => decision. POST /api/pause body {paused}. POST /api/test => create backend Mock test event (cannot dial live via this endpoint). POST /api/providers/check body {provider,remote:false}; local checks default. POST /api/voice/preview body {text?,voice?,rate?} => audio/wav. GET /api/voices => [{id,name,language}]. POST /api/integration/install => reversible current-project AGENTS managed block only, optional project MCP config shown separately; GET /api/integration => status/commands. Additional real-call authorization routes must require explicit UI action and never unlock via config save.
- CLI: report --type TYPE --task-id ID --summary TEXT [--decision-json JSON]; report-and-wait same plus --timeout seconds; ping. Reads .local/connection.json (url/token); supports --connection file; task source bound to CODEX_THREAD_ID/CODEX_SESSION_ID when present. Decision id generated by server, never caller-supplied. Use stdin for detailed sensitive content. No hardcoded machine paths.
- MCP exposes ping/report_event/report_and_wait/get_decision using same backend. Project installer edits only current project, managed block reversible, not global config. Existing sessions can use CLI without MCP reload. Calls are genuine only when actual Agent invoked; UI test fixtures labelled Mock.
- Preserve turn_finished vs task_completed evidence distinction. Core event types: task_completed, task_failed, task_stalled, retry_exhausted, decision_required, turn_finished. Event summaries are short, no arbitrary raw logs.

## Provider contracts
Shared types src/shared/contracts.ts authoritative. Implement exported createProviders(): Record<ProviderId,CallProvider>. Provider calls do not independently retry. mock returns completed. SIP registration in root integration when available. core worker invokes dial; only explicit permitted real calls can invoke non-mock. Unknown timeout outcome returns unknown (never retry). Twilio webhook handler installed on separate callback listener, not exposed management listener; all callback paths validate full externally configured URL + signature and task binding. Aliyun uses official SDK and polling instead of public callback. Provider unit tests inject HTTP/SDK clients, no network cost.

v0.1.5 adds pushplus/ihuyi/ronglian. New HTTP adapters accept a third dial argument `{signal}`; emergency pause, configuration save, authorization revocation and the worker deadline abort pending preparation/transmission. An abort after dispatch cannot prove remote cancellation and must not trigger redial. pushplus must verify the account's complete bound phone matches the consented destination before sending; unknown/masked binding fails closed. Its delivery status is not evidence of answered audio. New adapters expose no public callback routes. A dedicated authenticated `/api/pushplus/account-check` performs explicit read-only identity checks; it never grants calling authorization. Old encrypted configs receive new empty provider groups in memory, with all new credentials included in masking.

## UI
Chinese first-run wizard, dashboard, configuration, records, integration, SIP section. Real backend, persistent config, masked secrets. Show +86 route limitation and separate mock/real mode plainly. User decision card maps options only; PIN only needed real telephone input, never approval escalation. Show current permission and latest actual agent contact. Backend handles all provider/model logic.
