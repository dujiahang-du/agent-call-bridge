# pushplus 电话标题通知

本适配直接调用官方 HTTPS 接口，只向账号本人绑定的中国大陆手机发送短标题通知。接听不需额外 App。**已完成本地 HTTP 契约测试、真实账号只读核对，且用户反馈主分支修复后的真实电话测试正常。** 电话结果来自用户确认，未由 Agent 独立听取；扣费/退款、长期接通率和其他账号仍未验收。

## 集中配置清单

1. 在 [pushplus 官网](https://www.pushplus.plus/login.html)完成个人实名并绑定本人手机号。实名校验收费，具体金额以支付页为准；不要向本项目、聊天或 GitHub 提交身份证。
2. 打开官网[开发设置](https://www.pushplus.plus/uc-dev.html)，在“开放接口”一行点击“修改”，勾选启用并确认。设置 `secretKey`，把这台电脑访问 pushplus 的实际出口公网 IP 加入安全 IP 列表，多项用英文分号分隔。代理可能按网站分流，其他查 IP 网站返回的地址不能证明 pushplus 看到的是同一个地址。IP 变化可能需要更新；不要填写路由器的内网地址，也不要开放任意来源。
3. 在本项目设置中选择 pushplus，填写**用户 token**和 `secretKey`，并填写相同的本人接听号码。消息 token 不适用于账号核对。两项凭据保存在后端私密配置，不进入浏览器返回值或公开仓库。
4. 点击账号核对：仅交换短期访问凭据、读取个人资料，不发送通知。必须能核实账号、完整绑定手机号、实名状态及至少 30 积分。**官方示例中的手机号和 token 均已隐藏；若真实接口也仅返回掩码，本适配会拒绝拨号，不能用手工勾选绕过。**
5. 在官网核对当前语音可用性及费用后，由本人决定是否充值。首次真实测试需在本项目单独确认，填写凭据不代表授权拨号。

请勿在其他客户端频繁刷新同一账号的开放接口凭据，以免相互失效。账号核对会读取服务商返回的个人资料，但仅使用校验所需字段，不保存或回显完整资料。

真实接口的 `expiresIn` 有效期字段可能返回数字字符串，与官方示例中的数字类型不同。适配器同时接受数字和有界纯数字字符串，仍限制缓存最多两小时并提前一分钟刷新；异常格式不会触发通知。旧版本出现“返回内容不符合账号接口约定”时，更新并重启后重新核对。

官网还提供默认预处理和消息规则。用于本项目的账号应关闭转发、预处理及改写接收人的规则，并在真实验收时核对最终接收人。本适配只请求已核对的本人通知，不能保证控制或屏蔽服务商账号上另设的规则，也不会擅自修改远端设置。

## 限制与失败处理

账号核对会区分 JSON 返回码：401 检查开放接口启用；403 检查本次请求出口 IP 和安全名单；903 检查用户 Token；900 停止重复请求并核对账号限制。600/999 不能单独认定为 SecretKey 错误。HTTP 网关错误和连接超时分别提示，不原样展示服务商可能含私人资料的消息。官方依据：[返回码](https://www.pushplus.plus/doc/guide/code.html)。

- 每次通知 30 积分（0.30 元），平台说明未接通等渠道失败可延迟退积分。官网明确警告接通不稳定；22:00—次日 08:00 连续拨打限制更严。
- 仅播报标题；本适配最多 100 个 UTF-16 单元，长摘要截短。正文只重复短标题。声音由服务商控制，本地音色、语速不改变电话播报。
- 每次发送前重新核对绑定手机；不支持群组、好友、任意号码或消息预处理。不提供电话按键回复、自由语音对话或远程挂断；需要决定时请回到本机界面。
- 提交成功只表示受理。查询的“已发送”是平台消息投递状态，**不能证明手机接听、听完或任务验收**。异常响应、超时及未知结果不自动重拨；停止只能保证阻止尚未提交及后续本地请求，不能保证撤回平台已受理的电话。
- 固定使用官方 HTTPS 主机，禁止跳转；手机号和凭据不进入 URL。访问凭据仅在进程内缓存，换配置及退出时清理；本适配不使用公共回调。

真实验收需本人确认一次通话后检查：账号核对能否返回完整号码、原生电话铃声、中文标题、官网发送状态与实际接听的一致性、扣费/退积分，以及本地暂停能否阻止后续通知。全部通过前不能称该线路已实测可用。

## 官方依据（核实于 2026-09-27）

- [语音渠道说明](https://www.pushplus.plus/doc/channel/voice.html)：绑定手机、播报标题、费用与接通风险。
- [实名认证说明](https://pushplus.plus/doc/function/verify.html)：个人实名及收费。
- [消息接口](https://www.pushplus.plus/doc/guide/api.html)：`POST /send`、`channel=voice`、异步受理与过期时间。
- [开放接口](https://www.pushplus.plus/doc/guide/openApi.html)：开发设置、安全 IP、`getAccessKey`、`user/myInfo`、`message/sendMessageResult`。
- [系统额度](https://www.pushplus.plus/doc/guide/use.html)：普通实名标题 100 字及平台频率限制。

按上述公开接口文档自行实现，不复制第三方示例或未明确授权的代码。测试仅使用合成数据和注入的内存/本地 HTTP 响应，未调用真实发送接口。
