# 个人用户拨打 +86 手机：线路候选

核实日期：2026-09-27。目标是直接拨到中国大陆手机号码，不以手机 App 来电或本地 SIP 演示替代。**当前没有完成个人账号审核和真实拨通验收的线路。**

## 阿里云为什么不能直接用

[官方企业资质要求](https://help.aliyun.com/zh/vms/user-guide/enterprise-qualification-management)明确不接受个人用户，个体工商户、自然人独资企业和个人独资公司也在不支持范围。语音业务资质审核是运营商的入网要求，独立于账号实名认证；改程序或换 Key 无法解决。已有合格企业也必须经过语音资质、场景和模板审核。

## 国内优先试验候选：pushplus（推送加）

官方公开条件目前最贴近个人自用。**v0.1.5 已接入并完成离线接口测试，仍没有完成账号认证和真实拨号验证**。配置及验收步骤见 [pushplus 指南](pushplus.md)。

- [实名认证说明](https://pushplus.plus/doc/function/verify.html)提供个人姓名、身份证、本人实名手机号及短信验证码流程，未要求企业材料。发送与充值前必须实名；认证每次收费，具体金额需本人在付款页核对。
- [语音渠道说明](https://www.pushplus.plus/doc/channel/voice.html)明确主动拨打绑定手机号，接听后只读消息标题，不读正文。官网可绑定手机号，接听不需额外安装 App；这与本项目简短中文通知的方向匹配。
- 通话每次 30 积分，即人民币 0.30 元；未接通等渠道失败按文档退还积分，可能延迟。官方明确提醒接通失败概率较大，可能被手机或运营商拦截；22:00 至次日 08:00 有更严格连续呼叫限制。
- [系统额度](https://www.pushplus.plus/doc/guide/use.html)列普通实名用户标题上限 100 字。宜播报简短状态；未核实双向语音、按键回复、长报告或全部 +86 号段保障。
- [消息 API](https://www.pushplus.plus/doc/guide/api.html)有 voice 渠道。适配只请求已核对的本人通知，不设置群组或好友接收参数，保留 Bridge 去重/限频/单次授权；请关闭平台的转发及改写接收人规则。提交成功不能当作已接听。[开放接口](https://www.pushplus.plus/doc/guide/openApi.html)需另行启用并设置 Secret Key 和出口公网 IP；若资料接口仅返回掩码号码，本项目会拒拨。

本人办理入口：[官网登录](https://www.pushplus.plus/login.html) → 个人中心 → 实名及绑定手机。先查看当前语音渠道与费用，再决定是否付费；不要把身份证或 token 发到聊天。本次没有注册、认证、充值或真实呼叫；以后首次真实测试仍需单独授权。

## 海外备选云线路：Zadarma

- [官方外呼页面](https://zadarma.com/en/services/calls/)明确列出个人和企业账户。
- [中国目的地资费](https://zadarma.com/en/tariffs/calls/china/)当前列出中国手机 US$0.70/分钟，按整分钟计费；实际账户开通和费用以服务商确认及控制台为准。
- [官方 SIP 接入说明](https://zadarma.com/en/support/instructions/freepbx/freepbx14/)提供 SIP 用户名、独立密码及服务器。协议参数与现有 SIP 功能基本匹配是技术判断，不代表项目已验证该线路。
- 未核实：中国大陆个人能否通过当前开户审核、所需身份证明、是否允许低频自动中文通知本人、是否放行目标 +86 手机及可用主叫号码。不能仅凭价格表认定新账户可拨通；不应先充值碰运气。

可通过官网在线客服或[官方咨询入口](https://my.zadarma.com/tickets/create/)集中确认以下问题（未登录也可提交，答复发送至本人填写的邮箱；此处不是身份证明上传入口）：

> 我是中国大陆个人用户，没有企业主体。希望使用 SIP，仅在本人的 AI 任务完成、失败或需要决定时，低频拨打本人已同意接听的 +86 手机并播放中文语音，不用于营销。请确认是否允许此用途、中国大陆个人能否开户、需要哪些身份材料、+86 手机目的地如何开通、可用主叫号码及完整费用。是否必须购买虚拟号码？

尚未替用户注册、联系客服、认证、充值或拨号。获明确答复后由用户完成账号操作，通过本地 SIP 配置页填写凭据，再单独授权首次真实通话；随后核验铃声、中文音频、接通状态、费用、停止及限频。当前 SIP 按键尚未接入任务回复。

## 有自有固话时的替代路线

可评估“Bridge → SIP/FXO 网关 → 本人的运营商固话线路 → +86 手机”。[设备商官方资料](https://documentation.grandstream.com/knowledge-base/ht813-faq/)证实 FXO 支持 SIP 转 PSTN；普通 FXS-only ATA 只接模拟话机，不能提供外线。

这条路线需要实际已开通且能拨出手机的线路、合适硬件，并先向运营商确认接入设备及自动通知用途是否允许。硬件与线路/通话可能收费；本项目未做该硬件或运营商实测，不建议未核实前购买。

## 排除与未落实

- Callcentric 有个人 SIP 按次外呼套餐，但本次未核实 +86 当前开通条件及价格，暂不作为已确认方案。
